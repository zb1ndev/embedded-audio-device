# embedded-audio-device
This is the final project for my intro to electrical engineering course I finished a month in advance. Its kinda bad and only records about 4.5s of 16bit audio at 11khz. I would like to use the other core to multithread a write ring buffer so I can store the audio data in the 4mb flash that esp32-wroom they provided has. The ring-buffer may be a little overkill, I think the esp32 is fast enough to do that work on a single core without dropping data.
